BUILT FOR REAL DOWNLOADS

少一点等待，
多一点掌控。

核心下载流程由 Rust 运行。文件和任务记录保留在你的电脑上。

↗
01 / TRANSFER

为大文件而设计

按需选择 1–16 路连接，支持 HTTP/HTTPS。下载源不支持分段时自动回退单连接。

↻
02 / RESUME

随时暂停，接着下载

任务进度与分段状态保存在本机。退出后重新打开，继续未完成的文件。

▤
03 / MEDIA

选清晰度，再保存

解析 YouTube 与 B 站公开视频。分离的音视频使用内置组件合并，无需额外安装工具。
