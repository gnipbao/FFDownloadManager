# FFDownload v0.3.6

本版修复失败任务续传和历史文件显示，并支持为需要登录的文件提供本次下载授权。

## 更新内容

- 下载完成后，如果文件已被删除或移走，对应记录会自动从列表隐藏；失败和暂停任务仍保留。旧版本误标为失败的已删除文件记录也会正确隐藏。
- 失败后点击「重试」可继续原任务，复用已验证的分段和请求头。如果源文件已变化或无法确认其一致性，会安全重新下载，避免混合新旧内容。
- 成品已成功保存时，临时文件清理失败不再误报为下载失败。
- 普通 HTTPS 文件遇到登录授权问题时，可通过「授权后重试」提供 Cookie；新建下载也可填写。Cookie 仅保留在当前进程内，不写入任务记录或续传数据库，重启后需要重新填写。详见[文件授权说明](../file-download-authorization.zh-CN.md)。

## 验证

macOS 桌面端已验证：16 MiB 文件下载 12 MiB 后遇到 HTTP 503，点击重试只补齐剩余 4 MiB，最终 SHA-256 一致；删除测试成品后，列表自动隐藏对应记录。Rust 与界面回归测试、格式检查和 Clippy 检查通过。

续传仍受源站 Range 支持、文件一致性及访问权限限制。过期链接或登录授权需要更新，浏览器登录状态不会自动导入。

安装包与构建状态见 [GitHub Actions](https://github.com/gnipbao/FFDownloadManager/actions) 和 [Releases](https://github.com/gnipbao/FFDownloadManager/releases)。macOS 支持 Apple Silicon、macOS 13+；Windows 支持 x64、Windows 10/11。
