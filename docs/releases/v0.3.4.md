# FFDownload v0.3.4

本版保留 Rust 多连接下载、暂停续传、任务管理和视频链接解析，暂时关闭尚不稳定的资源捕获功能。

- 正式版隐藏资源捕获、后台浏览器捕获、视频号系统代理抓包和内核测速；旧的捕获页面地址会回到下载管理。
- 同时禁用发布版的捕获接口，避免隐藏入口后仍能启动代理或浏览器。开发模式保留实验功能，便于后续修复。
- 保留 YouTube、B 站、抖音、小红书等现有链接解析与音视频合并能力；平台可用性仍受登录状态和源站限制影响。
- 小红书优先显示经文件头检查的原始文件；网页播放版明确提示可能含水印。
- 完整单文件媒体下载复用已完成的校验结果，减少一次重复的全文件读取。
- 从本地测试版升级时保留下载记录，并继续处理该测试版遗留的代理恢复记录。

## 安装包

- macOS 13+ / Apple Silicon：`.dmg` 或 `.zip`。
- Windows 10/11 / x64：`-setup.exe`。
- `SHA256SUMS.txt`：本次安装包的 SHA-256 校验值。

安装包暂未使用发布者证书签名或 Apple 公证，系统可能显示安全提示。
视频号代理抓包仍有问题，本版不宣称该功能已修复或正式可用。

验证包含 Rust 单元与下载流程测试、桌面 IPC、发布模式功能开关、macOS/Windows 构建；具体结果以本标签的 GitHub Actions 为准。
