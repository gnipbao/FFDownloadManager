# FFDownload v0.3.7

本版改进 YouTube 解析遇到登录提示或超时的处理，并修复 Windows 构建测试的文件锁兼容问题。

- 保留已验证可读的高清画面和音频，避免因其他格式失败继续回退，最终超时或出现不必要的登录提示。
- 新增可选的「YouTube 网页 Cookie」入口，使用支持网页会话的播放器请求解析。授权只参与本次解析，不存盘、不发送给视频 CDN；输入框提交后清空。
- 播放器拒绝访问且只返回部分视频资料时，正确显示登录或验证原因，不再误报缺少标题字段。
- 改进登录提示并加入 Chrome / Edge 操作说明，见 [YouTube 授权说明](../youtube-authorization.zh-CN.md)。
- 修复 Windows 测试读取已独占锁定的空锁文件导致构建失败的问题。

截图样本已在本机网络下无需登录解析出 22 个格式，包括 1080p 和 720p。平台验证与网络环境有关；浏览器中能播放不代表匿名解析一定可用，Cookie 也不能代替访问权限。

安装包与流水线状态见 [GitHub Actions](https://github.com/gnipbao/FFDownloadManager/actions) 和 [Releases](https://github.com/gnipbao/FFDownloadManager/releases)。
