# FFDownload v0.3.10

本版改进 Windows 桌面启动与抖音解析，加入 Suno 音乐下载，并汇集授权下载和断点续传修复。

## 更新内容

- **Windows 桌面**：统一使用 GUI 子系统启动，补齐浏览器子进程的无控制台设置，避免启动应用、解析媒体或合并音视频时额外弹出黑窗口。
- **抖音解析**：改进公开单视频与分享链接兼容性，每次解析更新网络设置；公开接口未返回作品时，可使用本机 Chrome 或 Edge 读取网页正常加载后的数据，并准确匹配目标视频。
- **Suno 音乐**：支持可公开访问的单曲分享链接，按可用音频格式保存，无需单独填写登录授权。
- **授权下载**：HTTPS 文件支持 Cookie 与自定义 Header，包括 `Authorization`、`Referer`、`User-Agent` 等；修复授权未正确传递的问题。凭据仅在当前应用进程中保留。
- **失败续传**：支持更新授权后继续下载，复用有效分段；已删除或移走的成品自动从历史列表隐藏。
- **YouTube**：改进 Windows 代理切换、登录提示和部分分段连接失败的处理。

## 安装

| 系统 | 安装包 |
| --- | --- |
| macOS 13+，Apple Silicon | `.dmg` / `.zip` |
| Windows 10/11，x64 | `-setup.exe` |

退出旧版后安装新版。安装包内含音视频合并组件；`SHA256SUMS.txt` 可用于校验下载文件。当前安装包尚未使用发布者证书签名或 Apple 公证，系统可能显示安全提示。

## 使用范围

平台登录、地区和付费限制仍然适用；清晰度与音质以当次可访问的资源为准。链接或授权过期后需重新解析或补充授权，续传依赖源站分段支持与文件一致性。抖音网页备用解析使用独立临时浏览器，不读取日常浏览器的登录状态。

具体支持范围见[支持站点](https://github.com/gnipbao/FFDownloadManager/blob/v0.3.10/docs/supported-platforms.zh-CN.md)，授权使用方法见[授权下载说明](https://github.com/gnipbao/FFDownloadManager/blob/v0.3.10/docs/file-download-authorization.zh-CN.md)。请仅下载拥有权利或已获许可的内容。
