# FFDownload v0.3.11

本版修复部分 Instagram 公开帖子与 Reels 无法解析下载的问题。

## 更新内容

- **Instagram 解析**：兼容公开页面新的播放数据格式；原有接口不可用时，自动尝试公开网页解析。
- **作品匹配**：按作品编号核对播放信息，避免把页面推荐的其他视频当作下载目标；轮播帖子仅解析其中首个视频。
- **浏览器兼容**：改进网页打开与播放信息读取的超时处理，减少页面加载较慢时的解析失败。
- **下载检查**：开始下载前检查媒体地址可读性，沿用 Rust 下载内核的分段下载与暂停续传。

## 安装与使用

| 系统 | 安装包 |
| --- | --- |
| macOS 13+，Apple Silicon | `.dmg` / `.zip` |
| Windows 10/11，x64 | `-setup.exe` |

退出旧版后安装新版。在“新建下载”中粘贴 Instagram 单条帖子或 Reel 链接，保持“自动识别”即可。网页备用解析需要电脑已安装 Chrome、Edge 等兼容浏览器；它使用独立临时会话，不读取日常浏览器的账号或 Cookie。

本版已完成一条公开 Instagram 视频的实际解析、完整下载与暂停续传验证（720 × 1280，约 103 秒，22.3 MiB）。其他作品的格式与可用性仍以平台当次提供的资源为准；私密、需登录、地区受限或已删除的内容不在此次支持范围内。

安装包内含音视频合并组件；`SHA256SUMS.txt` 可用于校验文件。当前安装包尚未使用发布者证书签名或 Apple 公证，系统可能显示安全提示。

完整范围见[支持站点](https://github.com/gnipbao/FFDownloadManager/blob/v0.3.11/docs/supported-platforms.zh-CN.md)。请仅下载拥有权利或已获许可的内容。
