# FFDownload v0.3.5

本版改进文件链接识别，并新增汽水音乐分享链接解析。文件直链直接下载，支持的平台音视频页面先解析再选择下载格式。

## 更新内容

- 修复按整个平台域名识别视频的问题：平台的文件、归档和资源链接不会再被误送入视频解析。HTTP/HTTPS 文件下载不限文件类型，也支持没有后缀的地址。
- 新建下载增加「自动识别」「文件直链」「音视频解析」三种方式，识别不符时可手动切换。
- 保留完整链接中的括号、分号等合法字符及签名参数，避免修改链接导致下载失败；继续支持从分享文本中提取链接。
- 改进下载失败提示：HTTP 401 提示需要登录授权，403 提示访问被拒绝，404/410 提示文件不存在或链接已失效。
- 新增汽水音乐分享链接解析：后台浏览器捕获网页实际播放的音频，再交给 Rust 下载核心保存。需要本机安装 Chrome 或 Edge；可下载的音质与时长以网页实际播放资源为准。

## 使用说明

文件直链仍受源站的访问权限和链接有效期限制。浏览器登录状态不会自动共享给 FFDownload；需要登录的文件请使用带访问授权的有效直链，或在已登录浏览器中下载。切换为「文件直链」只改变处理方式，无法代替源站授权。

原有多连接下载、暂停续传、任务管理与音视频解析继续保留。平台解析可用性会受源站变化和访问权限影响。

## 安装包

- macOS 13+ / Apple Silicon：`.dmg` 或 `.zip`。
- Windows 10/11 / x64：`-setup.exe`。
- `SHA256SUMS.txt`：安装包的 SHA-256 校验值。

在 [Releases](https://github.com/gnipbao/FFDownloadManager/releases) 获取安装包。构建与附件发布状态以该版本的 GitHub Actions 和 Release 页面为准。

安装包暂未使用发布者证书签名或 Apple 公证，系统可能显示安全提示。
