# 支持站点与下载范围

将文件直链、单个视频或单曲的分享链接粘贴到“新建下载”，即可自动识别并下载，或选择可用的格式与清晰度。以下列出当前支持范围；不同安装包的功能以对应版本的发布说明为准。

## 可用性受限的站点

## 其他下载方式

- **文件直链**：支持 HTTP／HTTPS 的压缩包、文档、安装包、音视频及其他文件，也支持无后缀地址。下载源支持分段时可并行下载、暂停与续传；需要授权的地址可填写 Cookie 和自定义 Header。
- **网页媒体解析**：可识别部分网页中的视频、音频与已支持平台的嵌入内容；不保证任意动态网页都可解析。
- **HLS 点播**：支持部分未加密的完整点播资源，下载后保存为 MP4 或 M4A；不支持所有清单格式。

## 使用说明

- 支持范围以单个作品为主，暂不支持频道、播放列表或合集批量下载，也不支持直播录制、受 DRM 保护的内容及通用 DASH 清单。
- 清晰度、音质与完整时长以平台当次提供且可访问的资源为准。登录、地区与付费限制仍然适用，下载速度受源站、网络和磁盘影响。
- 分享地址或下载授权过期后，可重新解析或更新授权再试。请仅下载自己有权保存的内容。
