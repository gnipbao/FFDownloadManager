FFDownload 0.3.4 · macOS

适用于 Apple Silicon（M 系列芯片），最低 macOS 13。
安装：将 FFDownload.app 拖入 Applications（应用程序），然后双击打开。

下载位置：~/Downloads/FFDownload
任务与续传记录：~/Library/Application Support/com.ffdownload.manager

粘贴文件直链可直接下载；粘贴 YouTube、B 站、抖音、小红书视频链接后，先解析并选择清晰度。
应用自带音视频合并组件，无需安装 Rust、Node、Python 或 Homebrew。
小红书优先提供可读取的原始文件；网页播放版本会提示可能含水印。

本版暂不开放资源捕获、后台浏览器捕获和视频号系统代理抓包。
内核测速仅在开发模式提供。正常使用无需安装抓包证书或配置系统代理。
从之前的本地测试版升级时，会尝试恢复该测试版记录的原代理设置。
已有下载文件、任务和续传记录会保留。

关闭窗口：任务继续在后台运行，点 Dock 图标可重新打开窗口。
退出应用（⌘Q）：先保存下载进度；下次打开后点继续下载。
新建下载：⌘N 或 ⌘K。
文件菜单支持打开下载文件夹、暂停所有下载。

Web 工作台与桌面版使用各自的下载目录和任务记录。
本版没有自动更新功能。

此安装包使用本地临时签名，尚未使用 Apple Developer ID 签名及公证。
系统可能显示安全提示。安装要求和源码见：
https://github.com/gnipbao/FFDownloadManager
