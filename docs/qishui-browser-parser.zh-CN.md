# 汽水音乐网页音频解析

自 v0.3.5 起提供。以下单曲样本于 2026-09-28 完成验证。

## 使用

本机安装 Google Chrome 或 Microsoft Edge，启动本地工作台，在“新建下载”中粘贴汽水音乐单曲分享链接，点击“解析音频”，确认格式后开始下载。文件名自动使用歌手、曲名和实际音频后缀。

解析器会临时启动独立的无头浏览器。浏览器只负责打开分享页和播放页面已有的音频；下载任务、分段连接、暂停续传和文件保存由现有 Rust 服务处理。解析完成或失败后关闭临时浏览器并清理独立配置目录。

## 实现与范围

- `src/qishui.rs` 通过 Chrome DevTools Protocol 监听播放器实际产生的音频请求及响应，匹配分享页曲目 ID 和播放地址，只选择当前歌曲。
- 音频格式来自实际网络响应，大小优先使用 `Content-Range` 的完整长度，时长来自浏览器加载的音频元数据。页面元数据本身不足以生成下载任务。
- 网页的播放音频与应用内下载接口各自独立。解析流程使用实际播放请求；不会请求应用内下载接口，也不会将页面的下载套餐字段作为播放资源是否可用的判断依据。
- 媒体计划保留播放请求所需的 Referer、Origin、User-Agent。创建任务前，用 Rust 下载栈再次验证可读取性；文件按原格式保存，无需转码。
- 支持页面实际提供的独立音频文件。若只提供试听片段，按片段展示；不解密 DRM 音频，不承诺完整曲库、无损音质、登录后曲目或地区限制内容均可用。
- 不读取用户浏览器配置和登录 Cookie，不修改系统代理。现有通用资源捕获的发布开关保持原有行为，单曲解析通过普通解析入口使用。

下载质量以网页实际播放源为准。Chrome/Edge 页面引擎是运行时依赖，解析编排及下载内核使用 Rust。

## 本地验证

样本为用户提供的 [单曲分享页](https://music.douyin.com/qishui/share/track?track_id=7687463141597169715)。通过工作台完成解析、创建任务、Rust 下载与本地文件校验：

| 项目 | 结果 |
| --- | --- |
| 文件容器／编码 | M4A／AAC |
| 大小 | 2,480,336 字节 |
| 实际时长 | 153.266009 秒 |
| 音频参数 | 44,100 Hz、双声道 |
| 完整性检查 | ffprobe 识别成功，FFmpeg 整段解码无错误 |

测试覆盖曲目隔离、没有实际播放请求时拒绝仅凭元数据下载、试听时长、加密与非音频响应拒绝、CDP 命令响应之间的网络事件保留、文件名和媒体计划归一化。该样本验证流程可用，不构成下载速度对比或全曲库可用性保证。
